# 🚲 自行车骑鹈鹕 · 跨代模型前端擂台

> **在线试玩地址**：https://dingyi580.github.io/pelican-arena/

这是一个围绕统一前端考题 **「一辆自行车正在骑着一只鹈鹕（A Bicycle Riding a Pelican）」** 构建的跨代大模型交互式实机评测擂台。

## 核心亮点

- **规模**：收录 **160 只** 完整闭合、零外链的实时交互作品，覆盖 **15 大渠道**、**17 家主流模型厂商**。
- **极速按需加载**：首页仅加载元数据，所有模型作品按需拉取并静默预取下一对，手机与弱网环境同样秒开。
- **三大独立赛道**：🎯 纯裸考 API / 🛠️ Agent 盲写 / 👁️ 视觉自审，公平分赛对比。
- **丰富对决模式**：支持三条赛道内全循环 1v1、同模型跨渠道打假、同渠道明牌 PK，以及 **🎛️ 自定义模式 (A vs B)** 全自由编排（单挑车轮战、跨渠道团体战、跨厂商大战，均支持盲斗）。
- **本地无上限永久存档**：投票记录、Elo 天梯、自定义标签全部保存在访问者自己的浏览器 IndexedDB 中，多人访问互不干扰。
